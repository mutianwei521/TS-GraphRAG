Fig. S6 | Parameter and channel sensitivity of the strict fusion component. a–d, Changes in Top-1 partition accuracy with propagation weight β (a), aggregation depth (b), the joint semantic/community weight multiplier (c) and rank-vote retrieval depth k (d). e, Boundary pairs for the maximum absolute query pressure change; the upper and lower tick numbers denote the weak and strong boundaries in metres, respectively. f, Minimum cosine similarity for semantic retrieval candidates; the default applies no cutoff. g, Individual channel removals and uniform channel weighting. Colours and marker shapes identify H0 (no exclusion), H2 (location exclusion), H4 (demand-state exclusion) and H8 (joint location, magnitude and demand-state exclusions). Points show mean within-seed differences from the unchanged default, and whiskers show ±1 sample standard deviation of these paired differences across five Gaussian measurement-noise realizations (s.d. 0.02 m; seeds 41, 141, 241, 341 and 441), each using the same 540 fixed simulated queries. Default Top-1 accuracies are given in the legend. Dashed zero lines mark no change; grey bands in a–e mark the default parameter settings. Connecting segments in a–d and f join tested values only; points are not joined across categories in e and g. Axis ranges differ between panels, and no values or whiskers are clipped. All 33 perturbations and the fixed default are retained; no configuration is selected using these results. Weight multipliers and channel removals are followed by weight normalization; fingerprint and semantic retrieval use 2k candidates. The semantic cutoff differs from the inactive scenario-graph construction threshold. This one-factor analysis evaluates the fusion component rather than the subsequently frozen projection-only estimator and does not test all parameter interactions or LLM confidence gating. Source data are provided as a Source Data file.
