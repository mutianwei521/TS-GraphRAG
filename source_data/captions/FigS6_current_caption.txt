Fig. S6 | Prespecified sensitivity of the strict fusion engine. Cells show the mean paired difference in Top-1 accuracy from the fixed default for every one of 34 prespecified settings, evaluated under H0, H2, H4 and H8. Each setting uses the same 540 fixed simulated queries under five independent Gaussian measurement-noise realizations (standard deviation 0.02 m; seeds 41, 141, 241, 341 and 441). Column headers give the default accuracy; positive and negative cells denote increases and decreases in percentage points. All settings are displayed and no setting is selected using these evaluation results. Joint semantic/community multipliers and channel removals are followed by weight normalization. Retrieval k sets the rank-vote depth, with fingerprint and semantic retrieval using 2k candidates. Threshold pairs specify the weak/strong observation-amplitude boundaries. The four semantic cosine cutoffs filter semantic retrieval candidates; they are distinct from the scenario-graph construction threshold, which is not used in the scored inference path. The color scale is centered on zero with separately labeled negative and positive ranges; no values are clipped. Seed-level values and standard deviations are supplied in the Source Data. This is a one-factor sensitivity study and does not assess all parameter interactions or LLM confidence gating.
